# Sola Browser

Fast. Private. Yours. With AI Inside.

Premium private browser with built-in AI search.

## Features
- Built-in AI Search (Perplexity, You, Phind, Gemini, ChatGPT)
- Voice Search
- QR Scanner
- Multi-Tabs
- History & Privacy Dashboard
- Search Engine Picker
- Animated Premium Background
- Zero Tracking - 100% Local Storage
- Fast & Lightweight (15MB)

## Tech
Android Java, WebView, Min SDK 21, Target SDK 35, Edge-to-Edge Android 15
